# data/assessment

เจ้าของ: **P5 (tools)**

`skill_v1.json` แบบประเมิน 12 ข้อ + weights — ดู §6.3

แบบประเมินนี้ถามประสบการณ์ที่ผู้ใช้รายงานด้วยตนเอง ไม่ใช่คะแนนจากข้อมูลรายวิชา
แต่ละทักษะมีคำถามหลัก 2 ข้อ น้ำหนักข้อละ 1.0 และตัวเลือกมีค่า 0–4

สูตรใน `calculate_skill`: `round(sum(value × weight) / sum(4 × weight) × 100)`
คำถามที่ไม่ตอบนับเป็น 0 ตัวอย่าง: frontend ตอบ q1 = 1 และ q2 = 3
จะได้ `round((1 + 3) / (4 + 4) × 100) = 50` คะแนน

`get_assessment()` ส่งคำถามและตัวเลือกตาม contract โดยไม่ส่ง `weights` ให้ frontend
