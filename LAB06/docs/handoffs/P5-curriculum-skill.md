### 8.2 Skill assessment

สูตรแต่ละทักษะ: `round(sum(answer_value × weight) / sum(4 × weight) × 100)` โดยคำถามที่ไม่ตอบคิดเป็น 0 ตัวอย่างตอบ `q1=1`, `q2=3` และข้ออื่นเป็น 0: frontend = `round((1×1 + 3×1)/(4×1 + 4×1)×100) = 50`; อีก 5 ด้าน = 0 คะแนน ถ้าคะแนนเสมอกัน `top_skills` เรียงตาม `SKILL_KEYS` ผลคำนวณไม่ใช้การสุ่ม

ทบทวนข้อความเบื้องต้นแล้วพบว่าข้อ q2, q5, q8 และ q12 ใช้คำว่า “หรือ” ซึ่งผู้ตอบอาจตีความระดับประสบการณ์ต่างกัน ต้องให้เพื่อนลองอ่านและแจ้งข้อที่กำกวมก่อนปรับเวอร์ชันคำถาม; ยังไม่มีผล review จากทีม จึงยังไม่แก้ข้อมูลใน PR #8
